## How to use
Before using, there are some concepts that are needed to understand the correct functionality of the software:
**Click:** the action of touching the screen or using a [mouse](https://en.wikipedia.org/wiki/Computer_mouse) to press its left button
**Keyboard:** Physical or Digital medium to insert digital representations of the alphabet.
**Button:** Click-able section inside the software that causes a reaction.
 
 1. As soon as the aplication starts, a text and a text input will be shown in your screen, that means the application was correctly loaded
 2. You'll want to add a task, the basis of the program is that tasks can be appended manually by the user, so applying the knownledge adquired before, you will run a click to the section of the screen that represents the text-input field.
 3. Depending on your device, a keyboard will be available (either pysically or digitally) and you will be able to insert text in representation of the task.
 4. Then, you must save the changes, to do that, you'll have to press (via "click" o pressing the phyisical button) the *Enter* key.
Congratulations! you've added your first task, to learn more, read the [docs](http://example.com)!.
